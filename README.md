# Automação de Cadastro de Produtos

Projeto de automação desenvolvido em Python durante meus estudos de programação.

O programa utiliza PyAutoGUI para automatizar o cadastro de produtos em um sistema web, utilizando como fonte de dados uma tabela em formato CSV..

## 🛠️ Tecnologias utilizadas

- Python
- PyAutoGUI
- Pandas
- CSV

## ⚙️ Como funciona

O programa realiza as seguintes etapas:

1. Abre o navegador Google Chrome.
2. Acessa o sistema de cadastro.
3. Realiza o login.
4. Carrega os produtos do arquivo `produtos.csv`.
5. Percorre os produtos utilizando um loop.
6. Preenche automaticamente os campos do sistema.
7. Realiza o cadastro de cada produto.

## 📊 Base de dados

Os produtos são armazenados no arquivo `produtos.csv`.

A tabela contém informações como:

- Código
- Marca
- Tipo
- Categoria
- Preço
- Custo
- Observações

## 🎯 Objetivo

O objetivo do projeto foi praticar Python e aprender conceitos de automação de tarefas, manipulação de dados e estruturas de repetição.
